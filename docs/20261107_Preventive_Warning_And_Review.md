# 예방 경고 방송과 관리자 최종 검토

자동 경고와 최종 위반 확정은 별개입니다. ROI·안전모 정책·3초 연속 관측 및 완전한 클립 조건을 만족한 검토 전용 후보도 서버 접수 후 기존 방송 설정에 따라 예방 경고를 보냅니다. 경고했다고 위반으로 확정하거나 통계에 자동 반영하지 않습니다.

- 3클래스 모델은 기존 `--submit-review-candidates`를 사용합니다. `review_only=true`, 공개 신뢰도 미산정(`null`), 최초 `pending` 상태를 유지합니다. 검증된 미착용 신뢰도를 임의로 생성하거나 일반 이벤트 모드로 바꾸지 않습니다.
- 관리자만 비식별 영상을 확인해 확정·오탐·보류·검토 불가를 판단합니다. 확정 위반 통계는 기존 관리자 검토 결과를 사용합니다.
- 방송 사용 설정이 꺼져 있거나, 출력 node가 없거나 오프라인이거나, 언어에 맞는 템플릿이 없으면 방송하지 않습니다. 기존 동일 이벤트 중복 방지·구역/PPE/언어별 쿨다운·명령 만료·현장 PC 중복 실행 방지를 유지합니다.
- 검토가 끝난 이벤트의 늦은 제출 재시도와 관리자 방송 요청은 새 방송을 만들지 않습니다.
- 점검 기본 모드와 `--replay-buffer`는 후보를 제출하지 않으므로 방송을 만들지 않습니다.
- 방송 문구는 기존 관리자 템플릿을 사용합니다. 시연에서는 “안전모 착용 상태를 확인해 주세요.” 같은 예방 안내를 사용하고, 자동 경고를 최종 위반 판정으로 설명하지 않습니다.

## 시연 전 확인

방송 설정과 출력 node 연결·언어·온라인 상태를 확인하고 현재 3클래스 review 모드를 사용합니다. 테스트 방송 출력과 실제 후보→자동 큐→현장 PC 출력은 구분합니다. 이 변경의 격리 검증에서는 음성 출력을 가짜로 대체하며, 실제 모델·실제 스피커의 종단 확인은 별도로 진행합니다. 서버·호스트 코드는 같은 배포 버전으로 맞춥니다.
