# 여러 구역 이벤트 필터

`GET /api/events?zone=A&zone=B&limit=50&offset=0`

`GET /api/events/summary?zone=A&zone=B`

- 구역 파라미터를 반복하면 선택한 구역 중 하나에 속한 이벤트를 반환합니다(OR). 다른 필터와는 AND입니다.
- 기존 `zone=A` 호출은 유지됩니다. 생략하면 전체 구역입니다.
- 최대 50개, 각 값은 1~100자이며 중복 값은 조회 전에 제거합니다.
- 목록의 total과 요약 집계에 같은 조건을 적용합니다.
- 프론트는 체크박스 선택과 URLSearchParams.append('zone', value)로 전달하고, 필터 변경 시 첫 페이지로 이동하면 됩니다.
- offset은 유지합니다. 새 이벤트나 검토 상태 변경 시 페이지 사이에 항목이 겹치거나 밀릴 수 있으므로, 새로고침하면 최신 목록을 다시 확인할 수 있습니다. 커서 전환은 이번 범위에서 제외합니다.
