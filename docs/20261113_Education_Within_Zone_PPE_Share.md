# 교육 추천의 구역 내 PPE 비중

## 승인 범위
사용자가 승인한 것은 한 구역 안에서 여러 위반 중 더 많이 발생한 PPE 유형에 추가 가중을 주는 교육 추천이다. `_replace_education_recommendations`의 집중도 분모만 변경한다.

```
구역 내 PPE 비중 = 해당 분기·해당 구역·해당 PPE의 확정 이벤트 건수
                 / 해당 분기·해당 구역의 모든 PPE 확정 이벤트 건수
```

한 구역에서 안전모 20건·안전조끼 5건이면 각각 0.8과 0.2다. 다른 구역의 사건이 늘어도 이 값은 변하지 않는다. 고유 인원 수가 아니라 확정 이벤트 건수다. 같은 분기·동일 event_zone_snapshot 귀속을 사용한다. 카메라의 현재 구역을 분모에 섞지 않는다.

## 호환 API
추천 조회의 기존 `items[].score_breakdown.zone_concentration` 필드명을 유지한다. **새로 생성한 교육 추천에서** 이 필드의 의미는 '구역 내 PPE 비중'이다. 명칭이 남아 있어도 여러 구역 간 공간 집중도, HHI, 발생 확률을 뜻하지 않는다. 프론트는 이를 '해당 구역 내 위반 유형 비중'으로 표시하는 것이 맞다.

- 계산에는 원래 비율을 사용하고 기존과 같이 저장·응답은 소수점 둘째 자리로 반올림한다.
- 상위 3개 추천을 고르기 전에 모든 PPE 행으로 구역별 분모를 계산한다. 추천에서 탈락한 PPE도 분모에는 포함된다.
- 빈 분기에는 추천이 없으며 0으로 나누지 않는다.
- 미지정 구역의 NULL과 빈 문자열은 응답과 동일한 하나의 빈 문자열 구역으로 묶는다.
- 기존 API 구조와 추천 상위 3개 정책은 그대로다.

## 바꾸지 않은 것
PPE 전체 통계 및 구역별 통계의 별도 점수식, 위험도 상수 1.0, 기존 계수 0.5/0.2/0.2/0.1, 반복 주수, HHI, 전체 점수 정규화는 변경하지 않았다.

교육 추천 점수:
`0.5 × 확정건수 + 0.2 × 반복주수 + 0.2 × 구역내 PPE 비중 + 0.1 × 1.0`

이 계수는 정규화된 50/20/20/10% 비중을 뜻하지 않는다. 새 비중 항목의 기여 범위는 0~0.2이고, 확정건수 등의 항목은 별도로 더한다.

## 기존 저장값·적용 주의
기존에 저장한 추천 행을 자동 재생성하거나 과거 분기를 일괄 변경하지 않는다. 기존 추천 캐시에는 이전 전체 구역 분모로 계산한 값이 남을 수 있으므로 해당 분기의 추천/통계를 **명시적으로 재생성한 뒤** 새 의미로 해석해야 한다. 현재 테이블에는 계산 정책 버전 필드가 없으므로 새 API에서 기존 저장값을 자동으로 새 정책값이라고 보장하지 않는다.

새 비중은 추천 순위를 바꿀 수 있다. W07의 저장 대상 보호를 사용하는 프론트와 함께 연결해야 하며, 편집 중 대상이 바뀌면 409 처리와 재선택이 필요하다. 이번 작업은 프론트를 수정하거나 운영 서버에 배포하지 않는다.

## 검증
20+5의 0.8/0.2, 다른 구역 추가의 독립성, KST 분기 경계·confirmed만 포함, 카메라 재배정 후 snapshot 유지, 미지정 구역·빈 분기, 상위3개 외 PPE의 분모 포함을 회귀 검증한다. 실제 PostgreSQL과 운영 화면 검증 여부는 별도 보고한다.
