# 교육 자료 작성·검토·게시 API (#111)

교육 추천의 주제에 본문·체크리스트를 연결하고 관리자가 승인한 자료만 작업자에게 제공합니다. 기본 작성·수정·승인·게시 구조는 공급업체와 무관합니다. 이후 추가한 [OpenAI 초안 생성 API](20261027_Education_AI_Drafts_API.md)는 같은 초안·검토 흐름을 사용하며 기본 비활성입니다. 번역과 프론트 화면 변경은 포함하지 않습니다.

## 관리자 API

모든 아래 API는 관리자 Bearer 인증이 필요합니다. 미인증은 401, 작업자는 403입니다.

| API | 목적 |
| --- | --- |
| `POST /api/recommendations/{recommendation_id}/materials` | 새 초안 작성, 201 반환 |
| `GET /api/recommendations/{recommendation_id}/materials?limit=50&offset=0` | 해당 추천의 분기·구역·PPE에 속하는 자료 조회, 최대 100건 |
| `GET /api/education/materials/{material_id}` | 관리자용 내용·상태·작성/수정/게시 이력 조회 |
| `PATCH /api/education/materials/{material_id}` | 초안 수정, `expected_version` 필요 |
| `POST /api/education/materials/{material_id}/publish` | 검토 승인 후 게시, `expected_version`·`approved=true` 필요 |
| `POST /api/education/materials/{material_id}/unpublish` | 게시 취소 후 초안으로 전환, `expected_version` 필요 |

작성 본문은 다음과 같습니다. 수정할 때는 같은 내용에 `expected_version`을 추가합니다.

```json
{
  "title": "작업 전 안전모 점검",
  "body": "현장 지침에 따라 안전모의 상태와 올바른 착용을 확인합니다.",
  "checklist": ["외관과 손상 여부를 확인합니다.", "현장 지침에 맞게 착용합니다."]
}
```

제목은 1~200자, 본문은 1~12000자, 체크리스트는 1~20개이며 항목별 1~500자입니다. 공백만 있는 값은 허용하지 않습니다. 관리자 ID·게시 상태·통계·구역을 클라이언트 입력으로 받지 않습니다. 작성·게시 담당자는 인증 정보, 분기·구역·PPE·주제는 서버의 추천 정보에서 결정합니다.

관리자 검토 후 다음 요청으로 게시합니다.

```json
{"expected_version": 0, "approved": true}
```

버전이 다르면 `409 education_material_version_conflict`를 반환합니다. 게시된 본문은 직접 수정하지 않습니다. 수정본은 새 초안으로 작성하고 검토 후 게시합니다. 새 초안을 작성하는 것만으로 기존 게시 자료는 바뀌지 않습니다. 새 자료가 승인되면 같은 분기·구역·PPE의 기존 자료는 `superseded`로 바꾸고, 새 자료 게시와 함께 트랜잭션으로 반영합니다. 이전 승인 자료와 게시 담당자·시각은 유지합니다.

## 게시 취소

오류가 있는 자료의 노출을 중단할 때 `POST /api/education/materials/{material_id}/unpublish`를 호출합니다.

```json
{"expected_version": 1}
```

현재 상태가 `published`인 자료만 `draft`로 전환하고 버전을 증가시킵니다. 취소 담당자·시각은 `updated_by`·`updated_at`에 기록하며 직전 `published_by`·`published_at`은 유지합니다. 별도 전체 변경 이력 테이블을 추가하지는 않습니다. 취소 이후 작업자 조회의 `material`은 `null`이며, 이전에 `superseded`된 자료를 자동 복구하지 않습니다. 이미 작업자 화면에 표시된 내용의 즉시 회수는 프론트의 재조회가 필요합니다.

수정 후 다시 게시하려면 현재 버전으로 `approved=true`를 전달해야 합니다. 버전 불일치는 `409 education_material_version_conflict`, 게시 중이 아닌 자료는 `409 education_material_not_published`를 반환합니다. 새 DB 필드나 상태값은 추가하지 않습니다. 관리자 화면의 게시 취소 버튼은 프론트 담당이 별도로 연동합니다.

## 기존 작업자 API

`GET /api/worker/education`의 기존 `groups`, 최신 분기 선택, 미배정 안내, 최상위 호환 필드는 유지합니다. 각 추천의 `material`은 기존 프론트의 `string | null` 계약을 유지합니다. 승인 자료가 없으면 기존처럼 `null`이고, 승인 후에는 제목·본문·체크리스트를 합친 텍스트를 제공합니다.

```json
{
  "material": "작업 전 안전모 점검\n\n관리자가 검토한 본문\n\n확인 목록\n- 관리자가 확인한 항목"
}
```

관리자용 작성자·수정자·버전·초안과 추천 점수·위반 건수는 작업자 응답에 추가하지 않습니다. 로그인한 작업자의 현재 배정 구역으로만 조회합니다. 본문은 텍스트 데이터이며 프론트에서 임의 HTML로 실행하지 않습니다.

## 추천 재생성

기존 추천 ID는 분기·순위로 만들어져 재생성 시 다른 구역에 재사용될 수 있습니다. 자료를 그 ID의 외래키에만 묶으면 승인한 자료가 삭제되거나 다른 구역에 연결될 수 있어, 자료에 분기·구역·PPE·주제의 스냅샷을 저장합니다.

작업자에게는 현재 추천의 범위·주제가 일치하는 게시 자료만 제공합니다. 추천 주제가 바뀌면 이전 자료를 자동으로 새 주제의 승인 자료로 간주하지 않습니다. 추천이 사라지거나 내용이 바뀐 초안의 게시도 거절합니다. 이전 자료를 다른 분기나 구역에 자동 재사용하지 않습니다.

## DB·검증·후속

동의서 PR #167 이후의 스키마 v11→v12입니다. 기존 사용자·동의서·교육 추천을 보존하고 `education_material`을 추가합니다. 배포 DB는 이 PR에서 이관하지 않았습니다. #167을 먼저 반영하고 이 PR을 반영해야 합니다.

격리 테스트에서 초안 비노출, 관리자 승인, 수정 버전 충돌, 기존 게시 자료 유지·교체, 다른 구역·과거 분기 차단, 추천 ID 재사용, 주제 변경, 관리자 권한, v11 이관을 검증합니다. 실제 교육 자료의 안전 지침 검수는 관리자가 수행합니다.

후속 작업으로 기록합니다.

- 상용 AI 초안 생성: [OpenAI API 계약](20261027_Education_AI_Drafts_API.md)을 사용합니다. 실제 키·모델 설정과 유료 호출은 별도입니다.
- 게시 취소 API는 위 계약으로 제공합니다. 화면 연동은 프론트 담당 PR로 진행합니다.
- 프론트 담당: 관리자 작성·검토·게시 화면과 작업자 `material` 표시를 별도 PR로 연동합니다.
- 번역은 프론트 담당과 합의 후 결정합니다. 사용자별 선호 언어, 언어별 교육 텍스트 저장·승인 정책을 논의하며, 영상은 우선 한국어 단일본을 사용하고 자막은 일정에 따라 결정합니다. 이 API 변경에는 번역·자막 구현이 포함되지 않습니다.
