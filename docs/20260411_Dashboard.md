## 문서 개요

본 문서는 AI 기반 PPE 분석 시스템의 **어드민 대시보드 프론트엔드** 설계를 기술한다. 대시보드는 담당자가 AI가 생성한 후보 이벤트를 검토하고, 분기별 위반 통계를 확인하며, 교육 추천 결과를 열람하는 통합 인터페이스다.

본 문서는 `20260407_PPE.md`에 정의된 DB 테이블 구조, 분기별 분석 알고리즘, 데이터 흐름과 연계하여 작성하였다.

### 전제 조건

- **기술 스택**: React + TypeScript (풀 프론트엔드), 프로토타입 단계에서는 Streamlit 병행 검토
- **상태 관리**: React Context API 또는 Zustand (경량 전역 상태)
- **차트 라이브러리**: Recharts (React 기반, 경량)
- **백엔드 연동**: FastAPI 또는 Flask REST API (김재환 담당)
- **인증**: 담당자(reviewer) 로그인 기반 접근 제어

## 1. 화면 구성 개요

### 1-1. 전체 화면 맵

대시보드는 다음 4개의 주요 화면으로 구성된다.

```
어드민 대시보드
├── [홈] 요약 대시보드
│     ├── 이번 분기 후보 이벤트 수 (미검토 포함)
│     ├── 확정 위반 수 / 오탐 수 / 보류 수
│     └── 교육 추천 현황 요약
│
├── [검토] 후보 이벤트 검토
│     ├── 이벤트 목록 (필터: PPE 유형 / 구역 / 상태 / 날짜)
│     └── 이벤트 상세 + 검토 결과 입력
│
├── [통계] 분기별 통계 대시보드
│     ├── 요약 지표 카드
│     ├── PPE 유형별 위반 비율 (파이/바 차트)
│     ├── 구역별 집중도 히트맵 또는 바 차트
│     └── 전 분기 대비 트렌드 라인 차트
│
└── [추천] 안전교육 추천
      ├── 분기별 교육 추천 순위 카드
      └── 우선순위 점수 분해 뷰
```

---

### 1-2. 내비게이션 구조

| 경로 | 화면 이름 | 주요 역할 |
|---|---|---|
| `/` | 홈 요약 | 현재 분기 핵심 지표 한눈에 확인 |
| `/review` | 후보 이벤트 검토 | 이벤트 목록 조회 및 검토 처리 |
| `/review/:event_id` | 이벤트 상세 | 썸네일·영상 확인 후 검토 결과 입력 |
| `/stats` | 분기별 통계 | 구역·PPE 유형별 위반 통계 시각화 |
| `/recommend` | 교육 추천 | 분기별 추천 교육 주제 및 우선순위 확인 |

## 2. 후보 이벤트 검토 화면

### 2-1. 이벤트 목록 화면 (`/review`)

후보 이벤트 목록을 표 형태로 표시하며, 미검토 항목이 상단에 정렬된다.

**표시 컬럼**

| 컬럼 이름 | 데이터 소스 | 설명 |
|---|---|---|
| 이벤트 ID | `event_id` | 클릭 시 상세 화면으로 이동 |
| 발생 일시 | `timestamp_start` | 날짜 + 시간 표시 |
| 구역 | `camera_info.zone_name` | 이벤트 발생 구역 |
| PPE 유형 | `ppe_type` | `helmet` / `vest` |
| 지속 시간 | `duration_sec` | 초 단위 |
| 탐지 신뢰도 | `ai_confidence` | 0.00 ~ 1.00, 색상 인디케이터 포함 |
| 처리 상태 | `event_status` | `pending` / `confirmed` / `false_positive` / `hold` |
| 썸네일 | `thumbnail_path` | 50×50px 미리보기 이미지 |

**필터 옵션**

- PPE 유형 (`helmet` / `vest` / 전체)
- 처리 상태 (`pending` / `confirmed` / `false_positive` / `hold` / 전체)
- 구역 이름 (다중 선택 가능)
- 날짜 범위 (시작일 ~ 종료일)
- 신뢰도 임계값 이상만 표시 (슬라이더, 기본값: 0.5)

**정렬 기준**

1. 기본: 미검토(`pending`) 우선, 발생 시각 내림차순
2. 사용자 선택: 신뢰도, 지속 시간, 구역 이름 기준 정렬

---

### 2-2. 이벤트 상세 검토 화면 (`/review/:event_id`)

좌우 2열 레이아웃으로 구성한다.

```
┌──────────────────────────┬───────────────────────────────┐
│  [왼쪽] 미디어 영역        │  [오른쪽] 이벤트 정보 + 검토   │
│                          │                               │
│  대표 썸네일 이미지        │  이벤트 ID: EVT_0001          │
│  (클릭 시 영상 클립 재생)  │  발생 일시: 2026-04-07 10:02  │
│                          │  구역: 프레스 구역             │
│  영상 클립 플레이어        │  공정: 유압 성형              │
│  (재생 / 일시정지 / 구간   │  PPE 유형: helmet             │
│   반복 지원)              │  지속 시간: 3초               │
│                          │  탐지 신뢰도: 0.87            │
│                          │  사람 탐지: ✅                │
│                          │  PPE 탐지: ❌                 │
│                          │                               │
│                          │  ────────────────────────     │
│                          │  [ 검토 결과 입력 영역 ]       │
└──────────────────────────┴───────────────────────────────┘
```

---

### 2-3. 검토 결과 입력 UI

담당자는 다음 세 가지 중 하나를 선택하여 검토 결과를 제출한다.

| 버튼 | `review_result` 값 | 색상 |
|---|---|---|
| 확정 위반 | `confirmed` | 빨강 (`#E53E3E`) |
| 오탐 | `false_positive` | 파랑 (`#3182CE`) |
| 판단 보류 | `hold` | 노랑 (`#D69E2E`) |

**추가 입력 필드**

- `review_reason_code` — 드롭다운 선택
  - `confirmed_no_helmet` / `confirmed_no_vest`
  - `false_positive_occlusion` / `false_positive_angle`
  - `hold_unclear` / `hold_low_resolution`
- `review_comment` — 자유 텍스트 (선택 입력, 최대 200자)
- `second_review_needed` — 체크박스

**제출 후 동작**

- 검토 결과 저장 후 목록 화면으로 복귀
- 다음 미검토 이벤트로 바로 이동하는 "다음 이벤트 →" 버튼 제공 (연속 검토 생산성 지원)

## 3. 분기별 통계 대시보드 화면 (`/stats`)

### 3-1. 요약 카드 영역

화면 상단에 4개의 숫자 카드를 가로 배치한다. 데이터 소스는 `quarterly_stats` 테이블이다.

| 카드 이름 | 표시 값 | 보조 표시 |
|---|---|---|
| 후보 이벤트 수 | `candidate_count` | 전 분기 대비 증감 (화살표 + %) |
| 확정 위반 수 | `confirmed_count` | 전 분기 대비 증감 |
| 확정 비율 | `confirmed_count / candidate_count × 100` | 오탐 수 보조 표시 |
| 우선순위 최고점 | 해당 분기 `MAX(priority_score)` | 해당 PPE 유형 표시 |

분기 선택 드롭다운(`2026-Q1`, `2026-Q2`, …)을 제공하여 이전 분기 데이터도 조회할 수 있다.

---

### 3-2. PPE 유형별 위반 현황 차트

**도넛 차트** — 분기 내 전체 확정 위반 중 `helmet` 미착용 vs `vest` 미착용 비율을 표시한다.

**누적 바 차트** — 월별(1~3월 등) 위반 건수를 PPE 유형별로 색상 구분하여 쌓아서 표시한다.

```
           helmet    vest
4월  ████████████░░░░░░
5월  ███████░░░░░░░░░░░
6월  ██████████████░░░
```

---

### 3-3. 구역별 집중도 시각화

**수평 바 차트** — 구역별(`zone_name`) 확정 위반 건수를 내림차순으로 정렬하여 표시한다. 막대 색상은 우선순위 점수에 따라 단계적으로 표현한다(낮음: 초록 → 높음: 빨강).

| 구역 | 확정 위반 수 | 우선순위 점수 |
|---|---|---|
| 프레스 구역 | 18건 | 8.6 |
| 절삭 / 가공 구역 | 12건 | 6.2 |
| 자재 이동 구역 | 5건 | 3.1 |

공정 유형(`process_type`) 필터를 추가로 제공하여 특정 공정에 집중된 위반을 추려볼 수 있다.

---

### 3-4. 분기 비교 트렌드 차트

**라인 차트** — 최근 4분기의 확정 위반 건수 추이를 PPE 유형별로 선을 나눠 표시한다. `trend_vs_prev_quarter` 값을 각 데이터 포인트에 툴팁으로 표시한다.

```
확정 위반 수
  20 |       *
  15 |   *       *
  10 | *               *
   5 |
     Q3'25  Q4'25  Q1'26  Q2'26
     ─── helmet  ─── vest
```

## 4. 교육 추천 화면 (`/recommend`)

### 4-1. 추천 결과 카드

분기별로 생성된 `education_recommendation` 데이터를 추천 순위(`recommendation_rank`) 기준으로 카드 형태로 표시한다.

**카드 구성 요소**

```
┌────────────────────────────────────────┐
│  #1 우선 추천                           │
│                                        │
│  📌 안전모 착용 기준 및 착용 전 점검        │
│     절차 교육                          │
│                                        │
│  PPE 유형: helmet                      │
│  관련 구역: 프레스 구역                  │
│  우선순위 점수: 8.6                     │
│  생성 일시: 2026-06-30                  │
└────────────────────────────────────────┘
```

카드 테두리 색상은 추천 순위에 따라 구분한다 (1위: 빨강, 2위: 주황, 3위 이하: 회색).

---

### 4-2. 우선순위 점수 분해 뷰

각 추천 카드를 클릭하면 우선순위 점수가 어떻게 산정되었는지 분해하여 보여주는 모달 또는 사이드 패널을 표시한다.

**점수 분해 바 (4개 요소)**

```
확정 위반 건수   ████████████████░░░  (×0.5 → 9.0)
반복 발생 주차수  ████████░░░░░░░░░░░  (×0.2 → 1.0)
구역 집중도      ██████████░░░░░░░░░  (×0.2 → 1.2)
고위험 공정 가중  ████░░░░░░░░░░░░░░░  (×0.1 → 0.4)
────────────────────────────────────
총 우선순위 점수: 8.6
```

각 구성 요소의 실제 수치(`confirmed_count`, `repeat_weeks` 등)를 함께 표시하여 담당자가 판단 근거를 직접 확인할 수 있도록 한다.

## 5. 공통 컴포넌트 설계

### 5-1. 레이아웃 컴포넌트

```
AppLayout
├── Sidebar (고정 너비 240px)
│     ├── 서비스 로고 / 프로젝트명
│     ├── 네비게이션 메뉴 (홈 / 검토 / 통계 / 추천)
│     └── 로그인 담당자 이름 + 로그아웃
└── MainContent (나머지 너비)
      ├── TopBar (페이지 제목 + 분기 선택 드롭다운)
      └── PageContent (각 화면 컨텐츠)
```

---

### 5-2. 상태 배지 컴포넌트 (`StatusBadge`)

이벤트 처리 상태를 색상 배지로 일관되게 표시한다.

| 상태 값 | 표시 텍스트 | 색상 |
|---|---|---|
| `pending` | 미검토 | 회색 |
| `confirmed` | 확정 위반 | 빨강 |
| `false_positive` | 오탐 | 파랑 |
| `hold` | 보류 | 노랑 |

---

### 5-3. 필터/검색 바 (`FilterBar`)

이벤트 목록 화면과 통계 화면에서 공통으로 사용하는 필터 컴포넌트다.

```typescript
interface FilterBarProps {
  filters: {
    ppeType?: 'helmet' | 'vest' | 'all';
    status?: 'pending' | 'confirmed' | 'false_positive' | 'hold' | 'all';
    zone?: string[];
    dateRange?: { start: string; end: string };
    minConfidence?: number;
  };
  onChange: (filters: FilterBarProps['filters']) => void;
}
```

## 6. API 연동 명세

백엔드(김재환 담당)와의 연동을 위한 REST API 요청/응답 형식을 정의한다.

> **참고**: 아래 명세는 프론트엔드에서 필요한 데이터 기준으로 정의한 초안이다. 실제 엔드포인트 경로, 응답 구조, 인증 방식은 백엔드와 협의 후 확정한다.

---

### 6-1. 후보 이벤트 API

**목록 조회**
```
GET /api/events
Query: ppe_type, status, zone, date_from, date_to, min_confidence, page, limit
Response:
  {
    "total": 120,
    "items": [
      {
        "event_id": "EVT_0001",
        "camera_id": "CAM_001",
        "zone_name": "프레스 구역",
        "ppe_type": "helmet",
        "timestamp_start": "2026-04-07T10:02:15",
        "duration_sec": 3,
        "ai_confidence": 0.87,
        "event_status": "pending",
        "thumbnail_path": "/thumbs/evt_0001.jpg"
      },
      ...
    ]
  }
```

**단건 조회**
```
GET /api/events/:event_id
Response: 위 필드 전체 + video_clip_path, model_version, frame_sample_count
```

**검토 결과 제출**
```
POST /api/events/:event_id/review
Body:
  {
    "reviewer_id": "admin01",
```

## 7. UI/UX 설계 기준

### 7-1. 색상 및 시각 기준

산업 현장 안전 관리 시스템의 성격에 맞게 명확한 시각 계층을 유지한다.

|---|---|---|

| 경고 / 보류 | 노랑 | `#D69E2E` |
| 정보 / 오탐 | 파랑 | `#3182CE` |
| 완료 / 정상 | 초록 | `#38A169` |
| 배경 | 연회색 | `#F7FAFC` |
| 주 텍스트 | 진회색 | `#1A202C` |

---

### 7-2. 반응형 기준

초기 MVP는 **1280px 이상 데스크톱 환경**을 기준으로 구현한다. 태블릿 대응은 핵심 기능 구현 후 추가한다.

| 화면 너비 | 레이아웃 |
|---|---|
| ≥ 1280px | 사이드바 고정 + 2열 컨텐츠 |
| 768px ~ 1279px | 사이드바 접기 가능 + 1열 컨텐츠 |
| < 768px | MVP 범위 외 (추후 검토) |

---

### 7-3. 빈 상태 및 오류 처리

| 상황 | 처리 방식 |
|---|---|
| 미검토 이벤트 없음 | "이번 분기 검토 대기 이벤트가 없습니다." 안내 메시지 + 홈으로 버튼 |
| 분기 통계 데이터 없음 | "해당 분기 데이터가 아직 없습니다." 안내 메시지 |
| 교육 추천 미생성 | "분기가 완료된 후 추천이 생성됩니다." 안내 메시지 |
| API 요청 실패 | 토스트 에러 메시지 + 재시도 버튼 |
| 썸네일 로드 실패 | 이미지 대체 아이콘 (`broken image` 아이콘) 표시 |
| 영상 클립 없음 | "영상 클립이 저장되지 않은 이벤트입니다." 안내 표시 |
