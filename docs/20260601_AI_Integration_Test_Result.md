\# AI 안전모 탐지 통합 테스트 결과



\## 테스트 목적



AI 안전모 미착용 탐지 결과가 백엔드 후보 이벤트 저장 서비스, 경고 방송 서비스, API, 프론트 검토 화면까지 정상 연결되는지 확인한다.



\## 테스트 대상



\- 영상 파일 기반 탐지

\- USB 웹캠 기반 실시간 탐지

\- 후보 이벤트 DB 저장

\- 썸네일 저장

\- 경고 방송 및 TTS 출력

\- `/api/events` 조회

\- 프론트 후보 이벤트 검토 화면 표시
